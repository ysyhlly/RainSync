# 片库分页与扫描

`GET /api/v1/media` 仍返回影片数组，现在默认最多 100 条，`limit` 可设为 1–200。按影片 UUID 升序读取，用上一页最后一条的 `id` 作为 `after`；返回不足请求页大小时结束。`search` 为不区分大小写的标题子串，搜索新关键词时清空游标。下架条目不返回。翻页期间发生索引更新不保证跨请求快照一致性；刷新会从第一页重新读取。

网页一次只保存和渲染一页，通过上一页/下一页导航，在服务端搜索全库。旧客户端若不分页，只会看到默认第一页；Server 和 Web 应一起升级。

本地、HTTP、Jellyfin/Emby 扫描先枚举来源。本地 ffprobe 在数据库事务外运行，每准备好 32 项就以短事务提交一批。失败或中断保留已经提交的批次，但不执行缺失条目的下架。完整处理成功后才对本次完整资源集合做下架核对。因此扫描不是整库原子替换，扫描过程中可以看到已经提交的新条目。

迁移 `0011_source_scans.sql` 保存每个片源最新的扫描编号。每批写入与最终下架在短事务内锁定并核对编号；开始新扫描会使旧扫描之后的提交失效，防止晚到的旧扫描覆盖新结果。该表不保存后台任务进度，进程重启后仍须重新发起扫描。

Jellyfin/Emby 每页必须提供整数 `TotalRecordCount`；页间总数变化、尚未收齐却返回空页或累计数超过总数都会失败。远程枚举完成前不写入片目，因此这些错误保留原片库。上游持续变动时可稍后重新扫描。
