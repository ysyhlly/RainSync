# 实施状态

这是持续迭代中的可运行开发预览，不等同于长期计划全部完成。

全计划推进的工作包状态见 [实施进度](PROGRESS.md)。2026-09-27 已新增可复现基线采集、播放请求共用类型及额外 JSON Schema，并修复命令 ID 被不同载荷复用时误返成功的问题；W01 尚未全部完成。

后续同日已接通 [统一错误契约](API_ERRORS.md)：REST/Worker/WS 公开错误码、可读说明、重试标记和诊断编号；前端支持新旧错误形状并在会话失效后停止自动重连。

第三批已接通 [播放请求幂等](PLAYBACK_REQUESTS.md)，包含加密结果复用、准备记录、原子配额/会话/任务提交、续期保留和重启中断处理；客户端同操作有限重试复用原编号。尚未完成全部 W01/W06。

审查后已修复心跳数据库故障误报登录过期；播放准备的过期租约、旧执行者和暂时失败支持同 key 有限恢复，旧执行者不能覆盖新结果；活跃完成方案不受记录保留期提前阻断。生成 TS/Schema 由 CI 检查与 Rust 一致。

进一步区分命令控制权限与连接权限；播放请求支持按 key 取消，网页在准备失败或切换时撤销遗留会话。清理未确认的编号保留在当前标签页存储，阻止继续新建请求占用配额。

## 已实现

- Rust workspace、Vue Web、生成的命令协议类型与 Schema、Compose/Caddy、CI。
- Argon2 登录、管理员创建账户、Cookie/CSRF/Origin 校验。
- 房间 Actor、事务快照与事件、命令去重、版本检查、重启暂停、单实例锁。
- 房间邀请与撤销、成员权限、播放列表、聊天及历史。
- WebSocket 控制、时间校准、倍速纠偏、seek 冷却、增量事件/快照恢复、空闲 Actor 回收。
- 本地目录/HTTP 索引；Jellyfin/Emby 列表、播放协商、进度和停止上报代码。
- HTTP Range/HEAD/416、HLS 清单重写、加密分片授权、凭据加密。
- NAS 配对、目录索引、主动反向传输、设备撤销与有界背压。
- HTTP/NAS 经 Worker 鉴权读取的自动探测、基础兼容决策、转封装和转码；临时探测授权失败即停止，任务输入票据加密保存。
- Agent 数据连接复用其配置的服务入口；并发超限返回 503。
- FFmpeg 本地基础转码/转封装、任务租约与取消、音轨选择、内嵌普通字幕与同名外挂 SRT/VTT、范围外 seek 会话重建。
- 缓存容量/磁盘余量控制及基础 Prometheus 指标。

## 尚未完整实现

- Jellyfin/Emby 真实服务兼容性固定版本验证。
- 编码 profile/level/尺寸和上游设备档案协商仍未完成；已接入客户端 MP4/native HLS/MSE 检测及服务端传输协商。
- HTTP 跨域 HLS/CDN 跳转仍保守拒绝；远程字幕的完整样本矩阵仍待验证。
- 请求合并、跨会话分片复用、完整链路吞吐/首帧/重连指标。
- 移动实机、100 连接持续负载、弱网网络仿真、72 小时稳定性与真实媒体库备份恢复验收。
- Linux arm64 镜像的实测发布。

## 长期里程碑

v0.1 发布门槛是关闭上述首版缺口并完成真实设备和运行测试。之后依次进入多码率/硬件转码、边缘缓存、P2P 实验；当前没有把后续功能作为空壳 API 暴露。

遵循原计划的 24 周阶段顺序：基础和协议 → 同步闭环 → 四类片源 → NAS → 媒体兼容 → 弱网与运维 → 发布。已有代码缩短实现路径，但不能替代真实环境验收时间。

完整计划逐项证据和缺口见 [验收台账](ACCEPTANCE.md)。
