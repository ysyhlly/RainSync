## 已实现

- Rust workspace、Vue Web、生成的命令协议类型与 Schema、Compose/Caddy、CI。
- Argon2 登录、管理员创建账户、Cookie/CSRF/Origin 校验。
- 房间 Actor、事务快照与事件、命令去重、版本检查、重启暂停、单实例锁。
- 房间邀请与撤销、成员权限、播放列表、聊天及历史。
- WebSocket 控制、时间校准、倍速纠偏、seek 冷却、增量事件/快照恢复、空闲 Actor 回收。
- 本地目录/HTTP 索引；Jellyfin/Emby 列表、播放协商、进度和停止上报代码。
- HTTP Range/HEAD/416、HLS 清单重写、加密分片授权、凭据加密。
- NAS 配对、目录索引、主动反向传输、设备撤销与有界背压。
- HTTP/NAS 经 Worker 鉴权读取的自动探测、基础兼容决策、转封装和转码；临时探测授权失败即停止，任务输入票据加密保存。
- Agent 数据连接复用其配置的服务入口；并发超限返回 503。
- FFmpeg 本地基础转码/转封装、任务租约与取消、音轨选择、内嵌普通字幕与同名外挂 SRT/VTT、范围外 seek 会话重建。
- 缓存容量/磁盘余量控制及基础 Prometheus 指标。

## 长期里程碑

v0.1 发布门槛是关闭上述首版缺口并完成真实设备和运行测试。之后依次进入多码率/硬件转码、边缘缓存、P2P 实验；当前没有把后续功能作为空壳 API 暴露。

遵循原计划的 24 周阶段顺序：基础和协议 → 同步闭环 → 四类片源 → NAS → 媒体兼容 → 弱网与运维 → 发布。已有代码缩短实现路径，但不能替代真实环境验收时间。
