# 当前交付决策

这些条目记录现有源码的可核对约束，不补写未保存的历史讨论。
改变约束时在同一变更中补充原因、迁移/回退步骤和实际验证。

| 决策 | 原因与边界 | 相关材料 |
| --- | --- | --- |
| 默认整组使用同一提交的组件 | 尚无通用版本范围/features 协商；独立业务契约不能保证任意组合 | [兼容矩阵](COMPATIBILITY.md) |
| 日常制品与固定发布证明分开记录 | 日常基础标签/apt 可变；release lock 要求实际 digest、snapshot 与冻结源码 | [运行制品](RUNTIME_ARTIFACTS.md) |
| 数据库与材料分别加密、恢复只创建新库 | 源凭据/设备需要匹配 key；保留原库且先鉴别完整密文 | [备份运维](BACKUP_OPERATIONS.md) |
| 计算、P2P 与控制集群显式启用 | 存储、资源、节点授权和故障范围需由管理员明确配置 | [高级功能](ADVANCED_FEATURES.md) |
| 发布验收绑定同一最终候选 | 旧报告、模拟与短期结果不能证明新候选真机/长时稳定性 | [运维](OPERATIONS.md) |

插件删除只清除可编辑配置、回退快照和授权，不移除编译内置目录。保留单调修订标记及
不含配置正文的审计事实，避免旧草稿在删除后重新写入；默认不启用或自动重新授权。
迁移 0084、确认交互与回退要求见 [插件配置生命周期](ADVANCED_FEATURES.md#内置插件配置的删除与重新安装)。
