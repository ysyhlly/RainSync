# 管理员设置

管理员通过「管理员设置」统一查看实例级容量和功能配置。此页不会直接编辑环境文件，
读取设置不会修改数据库中的有效策略。当前可保存的全局项包含四个现有准入上限，以及显式注册和游客开关：

| 设置 | 部署基线 | 作用范围 |
| --- | --- | --- |
| 每账号播放会话上限 | `PLAYBACK_SESSION_LIMIT`，默认 2 | 同一账号未停止且未到期的会话与待准备请求 |
| 全局媒体准备队列上限 | `MEDIA_QUEUE_LIMIT`，默认 20 | 全部房间中拥有有效播放授权的排队、运行媒体任务；不是待播列表长度 |
| 注册码验证频率 | `REGISTRATION_VALIDATE_PER_MINUTE`，默认 30 | 每个来源地址、每分钟 |
| 注册尝试频率 | `REGISTRATION_PER_TEN_MINUTES`，默认 10 | 每个来源地址、每十分钟 |

四个数值项只接受 1–10000 的整数。来源地址仍由现有受信代理策略决定。

注册模式支持关闭注册、仅注册码和开放自主注册，初始仍为仅注册码。
开放模式允许不填注册码创建普通账号，沿用用户名/密码校验、密码哈希、来源限流和会话保护，
不会授予管理员身份或消耗邀请码。关闭注册不影响现有用户登录。
注册提交会在密码处理后重新锁定、核对当前策略，旧表单不能绕过刚关闭或恢复注册码的模式。
游客开关初始关闭，其房间访问和撤销规则由独立的游客授权流程执行，打开开关不授予管理权限。
公开的 `GET /api/v1/auth/registration-policy` 仅返回当前注册模式与游客开关。

## 保存、并发与生效

- `GET /api/v1/admin/settings` 返回十进制字符串 `revision`、当前 `values`、
  `defaults`、可空 `overrides`、`origins`、界限和毫秒时间戳 `updated_at`。
  `registration_mode` 为 `closed` / `invite_only` / `open`；`guests_enabled` 为布尔值。
  这两个新增访问选项的重置基线固定为 `invite_only` 和 `false`。
- `PATCH /api/v1/admin/settings` 接受
  `{"expected_revision":"1","changes":{"media_queue_limit":24}}`。
  省略字段保持原值，显式 `null` 恢复部署继承。未知字段、字符串数值、非整数和越界值均拒绝。
- 保存以数据库事务和修订检查一次提交全部字段。过期修订返回
  `409 SETTINGS_REVISION_CONFLICT`，表单必须重新加载并核对；语义不变的保存不推进修订。
- 读写都要求当前有效管理员；写操作还验证 Origin、CSRF、锁等待后的当前权限、
  精确登录会话及提交前真实时钟下的到期状态。返回体不缓存。
- 已提交的覆盖值持久化并由 Server/Worker 的实际准入路径从数据库读取。
  排队等待数据库锁的请求在准入判断前读取最新覆盖；已准入的请求继续原流程。
  降低上限不会主动停止播放、取消任务或清空队列，只有后续新准入受限制。
  注册窗口已消耗次数不会因调低再调高上限而减少。
- 配置表缺失或读取失败时拒绝准入，不退回无限配额。

四个数值项的「部署默认」指当前处理请求的进程在启动时已经验证的环境基线，不是硬编码默认数值。
覆盖仍在时，修改环境基线不会覆盖已保存的值；恢复继承后，新基线需重启相应进程才被读取。
控制节点、Server 和 Worker 的基线应保持一致。部署此功能必须整组更新兼容版本并应用
迁移 `0087_admin_settings`；旧二进制不会读取新覆盖，不能在混合版本期间假定策略已经全局生效。

## 只读与独立管理

私人库、NAS 计算、P2P、其他直播与预览处理容量在此页显示已配置状态。
这些状态不等同于节点在线或功能健康检查，也不暴露文件路径或原始环境内容。
数据库连接、密钥、网络监听、代理信任、安全参数、执行程序、存储路径以及
其他启动级开关继续由部署管理。

片源连接/凭据、NAS 节点策略、插件权限与配置、私人库访问规则、房间邀请及委派权限
保留各自作用域和既有编辑流程。管理员设置页提供相应管理入口，不会把这些对象改为全局配置。

## 验证

构建当前源码后，在隔离环境运行 `node tests/admin-settings.mjs`。
该脚本创建自己的回环 PostgreSQL 和 Server、短合成媒体文件，覆盖权限/CSRF/Origin、
保存/恢复/重启、并发修订、锁等待、限流及真实播放/媒体任务准入；不接受现有数据库。
另有 Rust 封闭请求与修订单元测试。隔离测试不代表生产配置、真实上游或长时负载验收。
