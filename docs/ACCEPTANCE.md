# 完整计划验收台账

此台账保留原计划范围。代码存在、模拟测试通过和真实环境验收是不同证据；没有证据的项目不算完成。每轮实施需更新 STATUS 与 VALIDATION，并沿此表继续推进。

| 原计划要求 | 当前证据 | 尚需完成或证明 |
|---|---|---|
| 单体控制面、独立 Worker、Agent、Compose | 工作区和运行中的四个 Compose 服务 | 镜像发布、升级兼容矩阵 |
| 权威 Actor、去重、事务提交后广播、重启暂停 | Rust 状态机、真实 PostgreSQL 事务故障和重启集成测试 | 扩大并发冲突与故障注入覆盖 |
| 房间、邀请、成员、播放列表、聊天 | API、Web UI、权限集成与浏览器交互 | 完整成员在线状态 UI 和管理流程审计 |
| 时钟、纠偏、断线增量恢复 | 独立同步引擎、算法测试、两浏览器真实播放 | 指定弱网矩阵、p95 与缓冲占比、恢复时限 |
| 本地、HTTP、Jellyfin、Emby | 本地/HTTP 真实播放；Jellyfin/Emby 模拟契约 | 固定真实上游版本与完整播放/拖动/音轨验证 |
| 能力协商与兼容决策 | MP4/native HLS/MSE 检测、类型生成、传输选择测试 | 编码 profile/level/尺寸、上游设备档案、实际解码失败降级 |
| NAS 主动出站、Range、撤销、有界数据 | 真实 Agent 容器和字节/转码测试 | 连续两小时、掉线/取消/并发/内存故障矩阵 |
| 转封装、音频转换、H.264/AAC 转码、字幕 | FFmpeg 真实解码、外挂字幕时间轴、远程不兼容编码自动转码 | 多音轨与远程字幕样本、长片随机拖动、进程清理压力 |
| 任务租约、缓存限额、磁盘余量 | 任务和缓存实现 | Worker 强杀恢复与磁盘不足实测、完整原子发布审计 |
| 身份、CSRF、目录限制、凭据隔离 | 认证与授权集成、路径校验、加密资源票据 | 重定向逐跳授权、限流/配额和全部 API 权限审计 |
| 公共 REST/WS 协议与 Schema | Rust 类型、生成 TS/命令 Schema | 所有接口/错误类型 Schema、查询接口完整性 |
| 监控与容量 | 基础 Prometheus、100 连接快照冒烟 | 首帧/吞吐/回源/缓存/重连指标、持续 100 在线控制面压测 |
| 桌面、Android、iOS | Chromium 真实播放、移动尺寸模拟 UI | Android 浏览器、iOS Safari 实机及后台恢复 |
| 发布恢复门槛 | 独立数据库 dump/restore、密钥恢复测试 | 72 小时、旧版升级、真实库灾难恢复、arm64 验证 |
| v0.2 多码率/硬件转码/HDR/ASS | 尚未实现 | 首版稳定后实现，分片关键帧对齐与切档时间轴验收 |
| v0.3 边缘缓存/合并回源/路由降级 | 尚未实现 | 实测瓶颈、相同分片只回源一次、鉴权与版本一致性 |
| v0.4 自愿启用 P2P 实验 | 尚未实现 | 上传限额/蜂窝禁用/校验/背压/HTTP 回退及节流收益验证 |
| 原生客户端、多实例 | 原计划为条件触发的独立项目 | 先取得浏览器或单实例限制证据，再制定独立实施范围 |

真机与长时间门槛不能用模拟环境或短时间冒烟替代。后续阶段也不能仅以目录、占位接口或配置开关计为实现。
