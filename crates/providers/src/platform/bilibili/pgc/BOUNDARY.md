# Bilibili PGC single-episode boundary

This is an offline-verified first slice, not a claim that Bilibili accepted a
live account, episode or media request. No live provider API, QR flow, credential,
media download, geo bypass or account acceptance was exercised for this slice.

## Source provenance

- SyncTV commit `ca91048b9da595e50642a61618b0eabfbc05e09b`,
  [Bilibili client](https://github.com/synctv-org/synctv/blob/ca91048b9da595e50642a61618b0eabfbc05e09b/synctv-media-providers/src/bilibili/client.rs#L2053-L2240):
  `/pgc/view/web/season?ep_id=...`, episode/section metadata identity and duration
  in milliseconds. Its old playurl wrapper is not evidence of entitlement and is
  deliberately not used as a fallback.
- Maintained yt-dlp
  [BiliBiliBangumiIE](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py#L938-L1026),
  inspected 2026-10-04: `/pgc/player/web/v2/playurl`, `result.video_info`,
  `play_check.play_detail` values `PLAY_WHOLE`, `PLAY_PREVIEW`, `PLAY_NONE`,
  `play_video_type` values `whole`, `preview`, `none`, and AreaLimitPanel's
  `config.is_block`. This mutable source is linked as an inspection reference,
  not an immutable capture or Bilibili API stability guarantee.
- The existing audited RainSync UGC DASH parser supplies bounded aliases,
  MP4 codec descriptors, SegmentBase ranges, CDN URL families, URL expiry parsing,
  qualities and duplicate-field JSON semantics. Only its expected-duration
  parameter was generalized; UGC request/resource/quality behavior is unchanged.

The checked-in JSON files are explicitly synthetic source-shaped parser
fixtures. IDs, titles, CDN paths and expiry values are fabricated test data, not
captured signed addresses or real account state. They demonstrate the known
envelope and signals, not current service compatibility. Negative fixtures are
generated by mutations in `tests.rs`, including denial, preview, unfamiliar
entitlement, DRM, encryption, identity mismatch and malformed track cases.

## Supported contract

- `ep<ID>` or exact HTTPS Bilibili `/bangumi/play/ep<ID>` URLs, optional trailing
  slash. IDs are positive canonical decimal strings, preserving full `u64`.
  Query/fragment, season/media selectors, short URLs, UGC and live are refused.
- Metadata selects exactly one matching episode, from bounded main or auxiliary
  section episode lists; duplicates or contradictory identity aliases fail.
  Selected episode `ep_id`, `cid`, `season_id`, `aid`, `bvid` and duration are bound.
- Exactly one fixed metadata request and one fixed v2 playback request under one
  deadline. The exact viewer's ordinary Bilibili cookie is optional and confined
  to those APIs. No host credentials, UGC route, legacy endpoint, webpage, token
  refresh, different region/account or denial retry is available.
- Direct API `code=0`, `result.video_info` envelope only. SSR `raw`/`data` wrappers
  and alternate historical shapes are deliberately unsupported in this slice.
- At least one recognized whole-playback field is required; every supplied
  recognized field must affirm whole. Missing, malformed, preview, none or future
  unfamiliar values fail closed. An opaque whole-entitlement proof is minted
  only after this gate. Presence of URLs, status zero, duration or paid account
  capabilities cannot substitute for that proof.
- API denials, explicit geo/access blocks, previews and DRM/license/encryption
  signals are refused before exposing descriptors. Advertised per-quality login
  and VIP requirements are capability metadata, not proof of viewing rights;
  protection signals in those advertisements are still rejected.
- Only clear AVC MP4 video and AAC-LC `mp4a.40.2` audio DASH is exposed. Every raw
  track is parsed/validated first, including filtered-out recognized codecs.
  No progressive, FLAC, Dolby, HEVC, AV1 or encrypted route is exposed.
- Native pixel height ceilings are distinct from Bilibili qn identifiers. A
  fixed qn request mapping and actual returned track height/current-quality
  filtering both apply. A ceiling with no compatible stream fails; it cannot
  silently choose a higher stream or make another request.

## Bounds and remaining gates

JSON: 2 MiB and unique object keys; metadata: 2,000 episodes/100 sections;
duration: 1 second to 24 hours and maximum 1.5-second full-duration disagreement;
tracks, URLs, backups and ranges reuse existing UGC hard bounds. Recognized URL
expiry is validated; expiry remains explicitly unknown if any retained address
lacks it. The server must preserve its hard descriptor/grant lifetime, account,
viewer, room, source/media revision and credential-generation checks, public DNS
pinning, redirect refusal and credential-free CDN request policy.

Live whole-episode/provider/account acceptance, a real browser playback loop,
database migrations, listeners, deployment and publication remain unverified.
Future response-shape changes require new reviewed fixtures, not permissive
fallbacks. PGC captions/danmaku, batches and season discovery are separate work.
